# Kanatix Video İndir — güncellemeler

Bu depo yalnızca **Kanatix Video İndir** uygulamasının otomatik güncellemeleri içindir.
Uygulama `version.json` dosyasına bakar; yeni sürüm varsa `KanatixVideoIndir.apk`'yı indirip kurar.

Elle kurmak için: [KanatixVideoIndir.apk](https://github.com/81Miralay81/video-indir/raw/main/KanatixVideoIndir.apk)
